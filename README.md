### ⚙️ System Design Focus
The recurring design pattern in my work is **Human-Centered AI**: combining structured extraction, verifiable outputs, and multi-agent coordination to address ambiguity while protecting the final clinical or educational output.

```text
       Multimodal Input (Text/Medical Docs/Images)
                             ↓
              Information & Feature Extraction
                             ↓
    ┌────────────────────────┼────────────────────────┐
    ↓                        ↓                        ↓
 NLP / LLMs             Generative AI            Vision Systems
    │                        │                        │
    └────────────────────────┼────────────────────────┘
                             ↓
             Confidence Assessment & Verification
                             ↓
         Interpretable Decision / Structured Report
```
